# Product Context

**Core Product:** A Windows file manager that can eventually replace Explorer for daily use. Treat this as a product engineering program, not just a UI project.

## Must-Have Capabilities
- folder navigation
- copy / move / delete / rename
- tabs
- address bar
- tree view
- file previews
- search
- thumbnails
- hidden files toggle
- network drives
- removable drives
- archive browsing
- drag and drop
- context menus
- multi-window support
- crash recovery
- settings sync
- theme support
- accessibility support
- keyboard-driven workflow

## Commercial Requirements
- does not freeze on large folders
- survives partial failures
- handles millions of files
- maintains user state
- logs errors cleanly
- supports future plugin/API changes
- can be updated without reinstalling from scratch
- does not rely on fragile hacks
- has a stable internal architecture
